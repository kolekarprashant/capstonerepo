Report Summary

Overview

This report presents the total sales revenue for the top 5 products, ranked by sales amount. Sales are calculated by summing (UnitPrice * Quantity * (1 - Discount)) for each product. The data was retrieved using the following SQL query:

SQL Query

SELECT p.ProductName AS Product, ROUND(SUM(od.UnitPrice * od.Quantity * (1 - od.Discount)), 2) AS TotalSales
FROM "Order Details" od
JOIN Products p ON od.ProductID = p.ProductID
GROUP BY p.ProductName
ORDER BY TotalSales DESC
LIMIT 5;
