Report Summary

Overview

This report presents the total sales of the top 5 products by revenue. It calculates total sales as SUM(UnitPrice * Quantity * (1 - Discount)). The following SQL query was executed to retrieve the product names and their total sales:

SQL Query

SELECT p.ProductName,
       ROUND(SUM(od.UnitPrice * od.Quantity * (1 - od.Discount)), 2) AS TotalSales
FROM "Order Details" od
JOIN Products p ON od.ProductID = p.ProductID
GROUP BY p.ProductName
ORDER BY TotalSales DESC
LIMIT 5;
